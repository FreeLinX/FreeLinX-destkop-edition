FreeLinX

A Linux distribution with a NetBSD userland, the musl C library and an LLVM toolchain. It contains no GNU software.

1. About

FreeLinX uses Linux 6.18, musl 1.2.5, clang/LLD for everything it builds, NetBSD's command line tools, runit as init and mdevd for devices. The package manager (xpkg), the installer (xsetup) and the boot code are written for FreeLinX.

"No GNU" is enforced by check-nognu.sh, which runs on every image and every package before release. It rejects ELF files built by GCC, linked against glibc, or carrying statically linked GNU code such as ncurses or readline.

There are two editions. base is a console system; this page describes it. The desktop edition (FreeLinX-desk) adds Openbox, Firefox and other graphical programs from the same package repository.

Current base release: 1.3.1. The ISO is 311 MB and boots on BIOS and UEFI.

Installed by default:

areasoftware
systemrunit, mdevd, dbus, doas, toybox (getty, login, ps, top)
shellmksh (interactive), NetBSD sh (scripts)
networkdhcpcd, wpa_supplicant, flxwifi, OpenSSH 10.5, curl, ntpd
toolsvim, tmux, htop, nnn, git, less, mandoc, tcc (as cc), fastfetch
bootLimine 12.9

X11, GTK and Mesa are not on the image. They are in the package repository.

2. Installing

Write the ISO to a USB stick and boot from it. Secure Boot must be off.

dd if=freelinx-base-x86_64.iso of=/dev/sdX bs=4M conv=fsync

In QEMU:

qemu-img create -f qcow2 flx.qcow2 20G
qemu-system-x86_64 -enable-kvm -cpu host -m 4096 -smp 2 \
  -drive file=flx.qcow2,if=virtio,format=qcow2 \
  -cdrom freelinx-base-x86_64.iso -boot d \
  -device VGA,xres=1600,yres=900 \
  -nic user,model=virtio-net-pci

To boot the installed disk, leave out -cdrom and -boot d. xres and yres set the screen size.

The live system starts a root shell. Run xsetup. It goes through these steps and remembers which ones are done:

setup-keymap      setup-hostname    setup-interfaces  setup-passwd
setup-timezone    setup-proxy       setup-ntp         setup-apkrepos
setup-user        setup-sshd        setup-disk        setup-lbu
setup-apkcache

setup-disk erases the chosen disk after you type yes. The disk needs at least 8 GiB and is partitioned as:

partitionsizecontents
ESP, FAT32, label FLX_BOOT1 GiBkernel, Limine
BIOS boot1 MiBLimine BIOS stage
ext4, label FLX_ROOT30% of the disk, 6 to 64 GiB/
ext4, label FLX_HOMEthe rest/home

The filesystems are recorded by UUID in /etc/fstab and /etc/flx-disk.

3. How the system boots

Live medium

Limine --> kernel + initramfs (flxlive) --> squashfs + tmpfs overlay --> /init --> runit

The ISO holds the kernel, a 290 KB initramfs and the system as boot/root.sfs (squashfs, zstd). The initramfs runs flxlive, a small static C program. It looks for the ISO 9660 volume FREELINX_LIVE, attaches root.sfs to a loop device, mounts it read-only under a tmpfs overlay (up to 75% of RAM), moves the medium to /media/flx and executes the system's /init. After boot the live system uses about 60 MB of RAM. If flxlive fails it prints the reason and starts a shell.

Installed system

Limine --> kernel (root=PARTUUID=..., ro) --> /init: e2fsck, remount rw --> runit

There is no initramfs. The storage drivers (virtio, NVMe, AHCI, USB mass storage) and ext4 are built into the kernel, which mounts the root partition read-only. /init runs e2fsck -p on it, remounts it read-write, mounts /home and a tmpfs on /tmp, and starts runit. If e2fsck changed the filesystem the machine reboots; if it cannot fix it, you get a shell. The boot menu has a "Rescue shell" entry that starts no services.

Services and consoles

Services live in /var/service: shell, dbus, ntpd, flxwifi, and sshd if enabled. flxconsole handles tty1 to tty3 and ttyS0. On the live medium it starts root shells. On an installed system (/etc/flx-installed exists) it runs getty and login, and restarts them after logout.

4. Packages

xpkg update
xpkg search editor
xpkg install tmux
xpkg upgrade
xpkg remove tmux
xpkg list -e

The repository index is signed with Ed25519 and checked against /etc/xpkg/keys. Each archive is checked against the sha256 in the index. An install that fails is rolled back. The repository has 428 packages and is hosted on Hugging Face.

5. X and Openbox

xpkg install xorg xinit openbox
startx

This also installs fonts, the st terminal and the XKB data. Without ~/.xinitrc, startx runs openbox and st. Right click on the desktop opens the menu. If you write your own ~/.xinitrc, start the terminal with exec openbox --startup st; a terminal started at the same time as openbox may not appear. xrandr -s 1920x1080 (package xrandr) changes the resolution.

Firefox (xpkg install firefox) needs about 500 MB. In a live session on a machine with 2 GB of RAM it does not fit; install to disk first.

7. Upgrading

Boot the new ISO on the installed machine and run flxupgrade. It replaces /usr, /bin, /sbin, /lib and /init on the root partition, adds new files to /etc without touching existing ones, and installs the new kernel and Limine. Users, settings, packages and /home are kept. Run doas xpkg upgrade afterwards.

Systems installed with 1.0.13 to 1.1.x ran from an image in RAM; flxupgrade converts them to the current layout.

8. Building

Any x86_64 Linux host. No root needed.

apt install git curl python3 openssl xorriso squashfs-tools cpio xz-utils binutils

mkdir FreeLinX && cd FreeLinX
for r in FreeLinX-base src ports drivers; do
    git clone https://github.com/FreeLinX/$r.git
done
curl -LO https://github.com/FreeLinX/toolchain/releases/download/v1.0.0/toolchain.tar.gz
tar -xzf toolchain.tar.gz

cd FreeLinX-base
sh build-base.sh

The result is out/freelinx-base-x86_64.iso. The build:

  1. copies src/rootfs;
  2. installs the base packages (musl, openssl, dbus, linux, linux-firmware, toybox, xpkg, musl-dev and others) from the signed repository;
  3. adds mandoc, less, iproute2, lsof, mksh, stty and tcc from ports/packages;
  4. removes what a console system does not use, and checks that every program's libraries are present, that no graphical program is left and that check-nognu passes;
  5. packs the system into root.sfs, builds flxlive, and writes a Limine ISO.

The build downloads about 150 MB. If the host has no xpkg, one is fetched from the repository by scripts/host-xpkg.sh (signature and sha256 checked). file-5.46.tar.gz comes from the FreeLinX source mirror. The build refuses a source tree with uncommitted changes unless ALLOW_DIRTY=1 is set.

Variables: SERIAL=1 (console on ttyS0), OUT, XPKG, SYSROOT, LIVECC, REPO, LIMINE_DIR, FLXSRC.

10. Commands

FreeLinX's own commands. For everything else see man.

xsetup [--list | --status | --reset step | step ...]
Install FreeLinX. Without arguments, runs every step not yet done.
xpkg [options] command [args]
search, show, install, reinstall, remove, autoremove, update, upgrade, outdated, list [-e], info, files, owns, verify, clean, repo list|add|remove. Options: -n (dry run), -f (force), -q, -v, --root dir, --allow-unsigned, --no-scripts, -V.
flxupgrade [-y] [disk]
Upgrade an installed FreeLinX from the live ISO of a newer release.
passwd [user]
Set a password. Non-root users go through doas. Uses flxpasswd and crypt(3).
flxadduser name [--admin]
Create a user with groups video, audio, storage, input, users; --admin adds wheel.
flxwifi scan | list | connect ssid [pass] | disconnect | status | off | auto
Wi-Fi via wpa_supplicant and dhcpcd. The passphrase can be passed in FLXWIFI_PASS.
flxpart --show disk | --create-standard [--esp-size MB] [--flx-sys-size MB] [--dry-run] disk
Show or write the GPT layout used by xsetup.
flxconsole
Console service (see section 3).
flxautomount, flxifconfig, flxroute, flxnet, flxtz
Mount removable media; configure an interface; set a route; network menu; set the time zone.

12. Known problems

  • Only tested in QEMU/KVM so far, not on real hardware.
  • No Secure Boot support.
  • eMMC disks cannot be used as the install target (the driver is a module and the installed system has no initramfs).
  • Wi-Fi has only been tested with a simulated access point.
  • nvi crashes on start. lemonbar and the imlib2 demo programs crash when no X display is available.

Report bugs at github.com/FreeLinX/FreeLinX/issues.
